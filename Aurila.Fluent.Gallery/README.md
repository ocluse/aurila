# Aurila Fluent Gallery

A standalone Blazor WebAssembly showcase for the Aurila Fluent 2 appearance package.

```powershell
dotnet run --project Aurila.Fluent.Gallery
```

The gallery demonstrates runtime brand ramps, semantic light and dark themes, typography,
elevation, action variants, fields, selection, navigation, cards, dialogs, bottom sheets,
spinners, progress rings, and Fluent 2 toasts.
