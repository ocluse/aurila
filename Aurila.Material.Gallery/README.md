# Aurila Material Gallery

A standalone Blazor WebAssembly showcase for Aurila's Material 3 appearance system.

## Run locally

```powershell
dotnet run --project Aurila.Material.Gallery
```

The gallery demonstrates dynamic seed colours, generated light and dark schemes, typography,
elevation, button and field variants, selection controls, navigation, cards, progress, snackbars,
dialogs, and bottom sheets.
